Voice Chat

You can still join with a vanilla client, but the voice chat won't work.
  1. Install Prism Launcher
    Note: You could use other launchers, but I found PrismLauncher to be the easiest to use
  2. Link your Minecraft account
  3. Drag & drop the VOFI.mrpack modpack into the launcher to create the instance.
  4. Join the server, then setup voice chat in-game.
Download VOFI.mrpack

Server-side Datapacks

Here is a list of tweaks the server includse. The aim was to keep everything feel like vanilla, but extend it with features that should be in the game

  • Minecart Improvements Changes behavior of minecarts, allowing them to move faster and more smoothly (among other changes).
  • Villager Trade Rebalance Tweaks the trades of several villager professions and wandering traders in an attempt to make them more fair.
  • Armor Statues Adds a unique book that allows you to alter the properties of armor stands in survival.
  • Mini Blocks Use a stonecutter to craft certain blocks into mini blocks (heads textured like blocks).
  • More Mob Heads Adds a chance to receive a mob's head upon killing it.
  • Player Head Drops A player will drop their head when killed by another player. The item displays who the killer is.
  • Silence Mobs Adds the ability to silence mobs using a name tag. 'Silence me'; 'silence me'; 'silence_me' are all acceptable names.
  • Painting Picker Use a stonecutter to choose a painting's variant.
  • Storm Channeling Start a thunderstorm by throwing a Channeling trident upward from the top of the world, consuming 150 (60%) durability.
  • AFK Display Greys out a player's name that is not moving for 5 minutes.
  • Universal Dyeing Allows you to dye any dyeable block to another color, no matter what color it is (does not include Concrete).
